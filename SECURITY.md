# Security Policy

## Supported Versions

Security fixes are provided on the default branch. Please use the latest
released version when reporting or validating a security issue.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security concerns privately through GitHub Security Advisories:

<https://github.com/berkayturanci/whatisnewdialog/security/advisories/new>

If GitHub Security Advisories are unavailable, contact the maintainer through
the email address listed on the GitHub profile. Include the affected version,
impact, reproduction steps, and any suggested fix. Reports will be acknowledged
as soon as practical.
